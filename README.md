# Vinux

Легковесный AI-чат-бот с терминальным интерфейсом на базе фреймворка Textual.

Что делает проект:
- Загружает и использует кастомную GPT-подобную transformer-модель (обучена с нуля)
- Предоставляет TUI (терминальный интерфейс) с меню, чатом, историей сессий
- Генерирует ответы на русском языке с настройками температуры, top-k, штрафа за повторения
- Сохраняет историю диалогов в JSON-файлы (папка sessions)
- Маскот-персонаж, который разбавляет строгий диа/зайн CLI приложения
- Система автодополнения команд (/exit, /clear, /back)
- Ведёт логирование чата в chat_log.jsonl

Структура:
- main.py — точка входа, главное меню
- config.py — конфигурация (название, версия, устройство)
- screens/ — экраны приложения (чат, история, стартовый экран)
- src/ — модули: генерация ответа, анимация, маскот
- styles/ — CSS-стили для Textual

Технологии:
- Python, PyTorch, PyTorch Lightning
- Textual (TUI-фреймворк)
- HuggingFace Tokenizers / GPT2Tokenizer
- Rich для форматирования вывода
